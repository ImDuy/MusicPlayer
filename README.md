# Music Player

## Features 🌟

- Browse and Play audio files from URL
- Play, pause, skip, loop songs
- Search songs
- Add to favorites/playlists
## Built With 🛠

- React Native (Expo)
- Typescript
- Redux toolkit
- React Native Track Player
